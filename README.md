## Custom Skies

Press **I** for a picker with every available skybox, grouped into categories, and switch whenever
you like without a reload. Skies ship inside the mod jar and can also be dropped into
`.minecraft/oyvey/skies`, including OptiFine and MCPatcher custom sky packs.

See [docs/custom-skies.md](docs/custom-skies.md).
