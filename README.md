> ### 🎮 PRISMA — das Horror-Spiel in diesem Repository
>
> Es liegt in [`game/`](game/) und hat mit dem Minecraft-Projekt darunter nichts zu tun.
>
> **Zum Spielen:** [Node.js 22 LTS](https://nodejs.org) installieren, dann
> **`SPIEL-STARTEN.bat`** doppelklicken (Windows) oder `./spiel-starten.sh` ausführen
> (macOS, Linux). Nicht `gradlew.bat` — das gehört zum Minecraft-Teil und schließt sich
> sofort wieder.
>
> Alles Weitere steht in [`game/README.md`](game/README.md).
>
> *PRISMA is a co-op horror extraction roguelite that lives in [`game/`](game/), unrelated
> to the Minecraft client below it. Install Node.js 22, then double-click
> `SPIEL-STARTEN.bat`.*
